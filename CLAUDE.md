# Notes for Claude

## STATUS.md (Jarvis dashboard)

`STATUS.md` at the repo root feeds the owner's Jarvis dashboard. Keep it true:
- Any change that ships something, starts or finishes a piece of work, or changes what is next or blocked updates `STATUS.md` in the same commit or PR.
- Move items between Now, Next, Blocked and Done recently. Keep Done to the last five or so.
- Set `updated:` to today's date. Change `phase`, `health` or `progress` only when they actually changed.
- Short lines, no em dashes. Format: https://github.com/ajaynss6/heyj-ai/blob/main/docs/STATUS_TEMPLATE.md
